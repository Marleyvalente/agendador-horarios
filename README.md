Appointment Scheduler API

A REST API for managing service appointments by professional. This project was built as a hands-on study project while learning Java and Spring Boot.

## Features

- Create appointments
- List appointments for a specific date
- Update an appointment using its current client and date/time
- Delete an appointment using its client and date/time
- Prevent overlapping one-hour appointments for the same professional

## Tech stack

- Java 21
- Spring Boot 4.1.1
- Spring Web MVC
- Spring Data JPA and Hibernate
- H2 in-memory database
- Maven
- Lombok

## Requirements

- JDK 21 or later
- Maven, or use the included Maven wrapper

## Run locally

Clone the repository and run the application from the project directory:

```bash
git clone <your-repository-url>
cd agendador-horarios
./mvnw spring-boot:run
```

On Windows PowerShell or Command Prompt:

```powershell
.\mvnw.cmd spring-boot:run
```

The API starts at `http://localhost:8080`.

> The database is configured as an H2 in-memory database. Its data is cleared when the application stops.

## API

Base path: `/agendamentos`

### Create an appointment

`POST /agendamentos`

```json
{
  "servico": "Haircut",
  "profissional": "Alex",
  "dataHoraAgendamento": "2026-10-10T11:00:00",
  "cliente": "Jordan"
}
```

Do not include `id` when creating an appointment; it is generated by the database. The current conflict check treats each appointment as one hour and rejects overlapping appointments for the same professional.

### List appointments for a date

`GET /agendamentos?data=2026-10-10`

Returns all appointments whose start time falls on the requested date.

### Update an appointment

`PUT /agendamentos?cliente=Jordan&dataHoraAgendamento=2026-10-10T11:00:00`

The query parameters identify the existing appointment. The JSON body supplies its new values:

```json
{
  "servico": "Haircut and beard trim",
  "profissional": "Alex",
  "dataHoraAgendamento": "2026-10-10T12:00:00",
  "cliente": "Jordan"
}
```

### Delete an appointment

`DELETE /agendamentos?cliente=Jordan&dataHoraAgendamento=2026-10-10T11:00:00`

### Date and time formats

Use ISO formats: `yyyy-MM-dd` for `data` and `yyyy-MM-dd'T'HH:mm:ss` for `dataHoraAgendamento`.

## H2 console

The H2 console is enabled at `http://localhost:8080/h2-console` while the application is running.

Use these connection settings:

- JDBC URL: `jdbc:h2:mem:agendamentos-db`
- User name: `sa`
- Password: leave blank
